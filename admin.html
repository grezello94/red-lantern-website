Timing shadow

A read-only calculation for currently active accepted/preparing/ready orders. It uses the saved course targets and production profiles.

Open Smart KDS to calculate active-order timing.

Priority scheduler shadow

A deterministic recommendation list. It ranks the earliest safe-start deadline first, then dish priority, order age, and a stable order number tie-breaker.

Open Smart KDS to calculate priority recommendations.

Batching shadow

Only compatible batchable dishes are grouped. A batch waits only while it remains safe, and each production task stays whole so live kitchen state is never ambiguous.

Open Smart KDS to calculate compatible batches.

Station capacity shadow

The most urgent work gets available station capacity first. Safe batches count as one allocation; work waiting for a batch is not allocated until its batch should fire.

Open Smart KDS to calculate station capacity.

Course pacing & synchronization shadow

Shows the next expected course for each table, holds dishes that must wait, and gives long-prep dishes a safe early start. Serve-together orders use the saved ready tolerance to finish together.

Open Smart KDS to calculate course pacing.

Fairness & anti-starvation shadow

An eligible item that waits beyond the configured fairness threshold is protected from being repeatedly overtaken. Urgent safe-start deadlines always remain first.

Open Smart KDS to calculate fairness protection.

Final Smart KDS recommendations

One deterministic, read-only view that applies course eligibility, urgency, fairness, and station capacity together.

Open Smart KDS to calculate final recommendations.

Table service-risk shadow

Highlights tables that have not received first food in time or have waited too long since their most recently served course.

Open Smart KDS to calculate table service risk.
